# Fonts

TIDELINE PRESS ships three fonts, all from Google Fonts under the
SIL Open Font License 1.1:

- **Anton** (`app/fonts/Anton-Regular.ttf`) — the giant 3-D cover titles.
  Source: https://github.com/google/fonts/tree/main/ofl/anton
- **Oswald** (`app/fonts/Oswald-Variable.ttf`) — billing block, labels, UI.
  Source: https://github.com/google/fonts/tree/main/ofl/oswald
- **Pacifico** (`app/fonts/Pacifico-Regular.ttf`) — the script subtitles.
  Source: https://github.com/google/fonts/tree/main/ofl/pacifico

Each font is downloaded from the google/fonts repository on GitHub
(raw.githubusercontent.com) and vendored under `app/fonts/` so the app works
fully offline. The full OFL 1.1 text ships with each font family in the
google/fonts repository; the fonts are used here unmodified, as the license
allows, with no Rockstar Games font involved anywhere.
